# 🎮 Java Game Arena

A console-based gaming application developed in Java that brings together four classic games in a single menu-driven program.

This project was created as a first semester programming project to practice Java fundamentals, problem solving, file handling, arrays, methods, exception handling, and game logic.

---

## 🎯 Games Included

### 🧩 Hangman
- Random word selection
- Limited guesses
- ASCII hangman drawing
- Player score tracking
- File handling for words and records

---

### 🧠 Memory Match
- Grid-based memory game
- Random emoji generation
- Matching pairs
- Score system

---

### 🔤 Word Scramble
- Country, Fruit, City and Mixed categories
- Easy, Medium and Hard difficulty levels
- Timer-based gameplay
- Score calculation

---

### ❌ Tic Tac Toe
- Multiplayer mode
- Single-player mode
- Computer opponent
- Toss system
- Winner and draw detection

---

## 🚀 Features

- Menu-driven interface
- Four games in one application

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project in your preferred Java IDE.
3. Ensure the required `.txt` files are in the project folder.
4. Run:

```text
GameArena.java
```
